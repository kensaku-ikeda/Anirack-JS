# anime-manga-log 要件定義書

アニメや漫画の記録ができるアプリを素のHTML/CSS/JSで作る。
目的はlocalstorageや非同期処理など、reactに進む前にJavaScriptの土台固めをするため。

## なぜTODOアプリではなくアニメや漫画の記録アプリなのか？

アニメと漫画が好きだから。
また、SNSとかに感想を乗せるのがハードル高い人にとっては個人でまとめられる
アプリがあると便利かなと思った。

## MVP これができたら最低限の完成　(CRUDアプリ)

- タイトルの保存　（C・作成）
- 作品ごとの感想を保存できる（C・作成）
- 保存したタイトルを表示するリスト　（R・読み取り）
- 保存したタイトルの名前を編集し、保存できる機能　（U・更新）
- 保存した感想を編集し、保存できる機能（U・更新）
- 保存したタイトルを削除する機能　（D・削除）
- 保存したタイトルがブラウザを閉じても保存できる機能　(localstorage)

## MVP完成後　あったらいいなと思う機能まとめ

- 作品ごとの評価をつけられる
- 今何話まで見てるかを進捗として保存できる機能

- APIなどで、作品のジャケットを取得できる（非同期処理）
- APIなどで、作品を検索することができる（非同期処理）
