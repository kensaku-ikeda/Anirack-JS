# 保存したタイトルを編集できるようにする(U・update)

## 手順

1. 編集ボタンを押したら入力や保存ができるポップアップを表示する。
2. キャンセルボタンが押された場合は、何もせずポップアップを閉じる。
3. それと同時にポップアップにタイトルごとのIDをもたせる？
   編集ボタンを押したときにわかったIDを一時的に保存する必要があるだろうか
   保存ボタンを押したときにも使いたいわけだし。
   グローバル変数に保存するかたちだろうか
4. タイトルが編集されて、保存ボタンが押されたら、mapでanirackContentRecordsに保存されている配列を１件ずつみて、idがポップアップと一致したらそのタイトルだけを更新したデータを返す（他の項目はそのまま）
5. 一致しなければそのまま帰す
6. 新しくできた配列をanirackContentRecordsに再代入
7. ローカルストレージに保存
8. 保存と同時に、ポップアップを閉じる
9. renderList()で再描画
