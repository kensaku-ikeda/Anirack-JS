# 感想機能の実装

記録ごとに感想を保存できるようにする。MVPデザインのも最低限感想保存できるので。

タイトルだけ記録して、まだ感想は書いていない作品のとき、reviewには""だけつくればいいのではないか。キーをなくすとundefiendが入力欄に表示されてしまうので。

追加ダイアログで基本追加して、編集ダイアログでも感想を更新できるようにする。
つまり両方 追加するときにも、感想をかけるし、とりあえずタイトルだけ追加してからあとでつけたすこともできる。

保存した感想は一覧のところには表示しない。編集画面で見たりいじれたりするような想定。

まだユーザ提供はしていないので、感想機能を作る前に保存した記録はとくに意識しなくていい。

## 手順

1. HTMLのdialog（追加・編集ともに）感想を入力できるtextareaタグを追加する。
理由はEnterキーで改行できるのと、文が端までいけば自動で折り返されるので、
長い文章を書く感想においては適していると判断した。

2. JSで感想を追加したときの保存の動作を実装。

3. 編集ダイアログを開いたときの表示の実装（既存の感想データを読み取って入力欄に表示）

4. 編集ダイアログで書いた文章でデータの更新の実装。
