# 作品名で検索して、作品を選んで記録できるようにする

## 使用するAPI

AniList APIを使用する。アニメ・漫画のデータベース管理・共有サイト「AniList」が提供しているGraphQLベースのWeb API

## やりたいこと。

- 追加ダイアログのタイトル入力欄に追加したいタイトルを入力すると、検索をすることができて、そこの候補からユーザーが選ぶと、追加したいアニメの正式名称で追加することが可能になる。

## 必要な知識

APIを扱うので、非同期処理やfetch/try/catch、async/awiteがひつようになるだろう。

## 実装手順

1. タイトルを入力し、検索ボタンを押したタイミングで
   「検索中・・・」を表示してから、fetchでAPIエンドポイントを使用し、クエリをPOSTメソッドで送信する。検索ワードに応じたデータを取得する。

2. 取得したデータをJSON形式に変換する。

3. 変換されたデータからタイトルを取り出して候補として表示する。候補を選択すると、そのタイトルが入力欄に入る。検索が成功したら「検索中・・・」を消す。data→Page→media→titleオブジェクトのnativeプロパティにあるぞ！

4. APIのデータ取得に失敗したときは、try/catchを使ってエラーを処理する。失敗したタイミングで「検索中・・・」を消し、「データの取得に失敗しました」などのエラーメッセージを表示する。
   また、検索結果が０件だった場合は、作品が見つかりませんでした。などのメッセージを表示する。

## 学んだこと

queryっていうのが、注文票みたいな役割で、そこに取得したいtypeと、variableにアニメタイトルとかを入力して、POSTで送信すると、サーバーからアニメ情報が帰ってくるという仕組みだ。
