## 記録した作品のジャケット画像を表示できるようにする

一覧に表示してえ。

## 手順

1. リストの表示をクリックしたときに画像のURLのパスを一時的な変数に保存する。

2. 画像のcontentRecordオブジェクトにimagePathプロパティにユーザーがクリックしたリストの画像のURLを値を入れる。

3. URLパスをローカルストレージに保存し、ページを再読み込みしても表示されるようにする。

4. 1で作成した一時的な変数の値をクリアする。

5. ローカルストレージからURLパスを読み取って、setAtribiteでsrc属性にいれる。

6. ローカルの作品データに、imagePathがない場合は、青い表示を表示させる。
