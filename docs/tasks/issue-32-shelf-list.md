# 棚でリストを表示する機能

## 実装手順

1. ### 棚を3列で表示する
   - リストを3冊ずつ並べ、次の行に折り返す。
   - `forEach` の第2引数から、0始まりのインデックスを取得する。
   - インデックスが3の倍数（`index % 3 === 0`）の項目から新しい行を始める。インデックスは `0, 3, 6, 9...` となる。

   **処理の流れ**
   - 3の倍数のとき：段・行・棚板を作り、行を外の変数に入れる。
   - 毎回：表紙を作って、その変数（今の行）に入れる。

2. ### 表紙クリックで編集する
   - 表紙をクリックすると、該当する作品の編集ダイアログを表示する。
   - 要素にボタンサイズを広げる必要がある。
   - 表示そのものをbutton要素にできるだろうか。

3. ### 削除操作を配置する
   - 削除操作を編集ダイアログの下部に配置する。
   - 編集ダイアログを開いた際に、UUIDを使って削除する。
