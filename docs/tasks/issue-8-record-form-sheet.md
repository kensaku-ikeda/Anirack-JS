# 入力フォームのボトムシートでの実装

## なぜ使うか、なぜそれを選んだか

dialogを開く形、開いたら入力フォーム以外の背景を暗くする、ただモバイルファーストなので、外側タップで直感的に閉じれるような動作をJSで加える。

## 今のHTMLのどこを、どう組み替えるか

追加で新しくdialogタグの部分を作ろうと思う、追加と編集の両方をHTMLで作る。
JSで書き換えるとなると実装が大変かつ、やることが多いので、こっちのほうが簡単

## 開く・閉じるのは、それぞれ何をきっかけにするか

下側にある＋記録ボタンを押すと、ボトムシートが下から表示され、入力欄と、下側には保存ボタン、左上の✕印で閉じることができる。外側タップでもキャンセル可能にする。

## 保存したあとの流れ

form.reset（）後にdialogを閉じる動作を加える
