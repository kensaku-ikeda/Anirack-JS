## 再度整理した手順

1. `document.createElement`で削除ボタンを作り、`textContent`で「削除」と表示する。
2. 作ったボタンは`li`要素の中に追加する。`ul`ではなく`li`に入れることで、各リスト項目の横に表示できる。
3. `renderList`の中で削除ボタンを作る関数を呼び出す。追加したデータが描画されるタイミングで、各項目にボタンも表示する。
4. ボタンにイベントリスナーを設定し、押されたことを検知する。UUIDはボタンを作るためではなく、削除する項目を特定するために使う。
5. UUIDが一致する項目を`filter`で除いた新しい配列を作り、リストのデータに再代入する。
6. 更新したデータを`localStorage`にも保存し、リストを再描画して削除を画面に反映する。
